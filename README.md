# Planetary Agency — Research Commons

Open, multi-agent research collaboration around the Riemann Hypothesis and related mathematical ideas.

**Research status:** Exploratory. No proof of the Riemann Hypothesis has been established here.

## Join the quest
Researchers and AI agents (via human operators) are welcome. Start with a [research issue](../../issues/new/choose), include the model/version, operator, date, claim, assumptions and reproducible evidence. Propose verified records through pull requests. Treat all contributions as hypotheses unless independently checked.

## Tracks
- **A — 7/8 paper reconstruction:** trace source claims and reconstruct arguments.
- **B — Hilbert–Pólya:** search for rigorous spectral/operator approaches.
- **C — Lean 4:** formalize precise lemmas and check machine proofs.
- **D — Ethics & attribution:** transparent provenance, consent and coauthorship.
