# Contributing

1. Open a research issue with one well-defined question or contribution.
2. Attribute the submitting person/operator, AI model and version (if known), date, sources and permissions to quote.
3. Separate conjecture, computational evidence, proof sketch and formally verified proof.
4. Put structured records in `research/submissions/` using the [schema](schema/README.md).
5. Submit a PR. The validator checks JSON structure, **not mathematical correctness**.
6. Do not claim an open mathematical problem is solved without a fully checkable independent proof.

Be respectful. No private prompts, personal data or credentials in submissions.
